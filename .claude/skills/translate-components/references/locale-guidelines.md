# Locale Guidelines for Translation

## Universal Rules

- **Informal address everywhere** — the brand is a knowledgeable friend, not a corporation
- **Adapt, don't translate** — rewrite for the target audience, preserving meaning and intent
- **SEO-aware headings** — titles and H2-equivalent text must use natural search terms in the target language
- **Keep brand name** — "Magic Heidi" is never translated
- **Keep CHF** — Swiss Franc references stay as CHF across all locales
- **Preserve technical terms** — words like "API", "SaaS", "PDF", "QR" stay in English

## German (de)

**Register**: Du-form, friendly, direct, practical

**Voice**:
- Always use "du/dein/dir" — never "Sie/Ihr/Ihnen"
- Swiss-German casual-professional tone: warm, knowledgeable, like a friend who's been through it
- Not overly formal Hochdeutsch — avoid stiff constructions
- Avoid Austrian idioms or Germany-specific references

**Characters**:
- ALWAYS use proper Umlaute: ä, ö, ü, Ä, Ö, Ü
- NEVER use ae, oe, ue substitutions
- Use ß where grammatically correct (Straße, außer, etc.)

**SEO notes**:
- German uses compound words (Buchhaltungssoftware, Rechnungsvorlage) — use them in titles
- Search terms tend to be noun-heavy — match this in headings
- Include Swiss-specific qualifiers where relevant (Schweiz, Schweizer, schweizerisch)

**Common adaptations**:
- "freelancer" → "Freelancer" or "Selbständige/r" (context-dependent)
- "invoice" → "Rechnung"
- "accounting" → "Buchhaltung"
- "tax return" → "Steuererklärung"

## French (fr)

**Register**: Tu-form, friendly, warm, professional

**Voice**:
- Always use "tu/ton/ta/tes" — never "vous/votre/vos"
- Swiss French: natural, no Parisian slang or verlan
- Warm and approachable but knowledgeable
- Avoid overly literary constructions

**Characters**:
- ALWAYS use proper French diacritics: é, è, ê, ë, à, â, ù, û, ô, î, ï, ç, É, È, etc.
- NEVER strip accents (e.g. "modèle" not "modele", "privée" not "privee", "créer" not "creer")
- This applies everywhere including YAML strings, titles, descriptions, and prose content
- Accent-less French is a critical quality failure — it reads as broken/machine-generated text

**SEO notes**:
- French keywords often include articles: "logiciel de comptabilité" not just "comptabilité logiciel"
- Use Swiss-French terminology where it differs (septante, nonante, etc. are fine)
- Include "Suisse" qualifier where relevant

**Common adaptations**:
- "freelancer" → "freelance" or "indépendant/e"
- "invoice" → "facture"
- "accounting" → "comptabilité"
- "tax return" → "déclaration d'impôts"

## Italian (it)

**Register**: Tu-form, friendly, direct

**Voice**:
- Always use "tu/tuo/tua" — never "Lei/Suo/Sua"
- Swiss Italian / Ticino-appropriate
- Warm, practical, direct — like a colleague giving advice
- Avoid overly formal or bureaucratic Italian

**Characters**:
- ALWAYS use proper Italian accents: à, è, é, ì, ò, ù, È, etc.
- NEVER strip accents (e.g. "perché" not "perche", "più" not "piu", "è" not "e" when it means "is")
- This applies everywhere including YAML strings, titles, descriptions, and prose content
- Missing accents in Italian change word meaning (e.g. "e" = "and" vs "è" = "is") — this is a critical error

**SEO notes**:
- Italian keywords: "software di contabilità", "fattura elettronica"
- Include "Svizzera" qualifier where relevant
- Ticino-specific terms are acceptable

**Common adaptations**:
- "freelancer" → "freelancer" or "lavoratore indipendente"
- "invoice" → "fattura"
- "accounting" → "contabilità"
- "tax return" → "dichiarazione dei redditi"

## Spanish (es)

**Register**: Tú-form, friendly, approachable

**Voice**:
- Always use "tú/tu/tus" — never "usted/su/sus"
- Neutral international Spanish — not Spain-specific (avoid vosotros, use ustedes for plural)
- Friendly and direct, practical tone
- Avoid regional slang from any specific country

**Characters**:
- ALWAYS use proper Spanish diacritics: á, é, í, ó, ú, ñ, ü, Á, É, etc.
- NEVER strip accents (e.g. "información" not "informacion", "también" not "tambien")
- Missing tildes change meaning (e.g. "año" = "year" vs "ano" = something else entirely)

**SEO notes**:
- Spanish keywords: "software de contabilidad", "factura electrónica"
- Use neutral vocabulary accessible across Latin America and Spain
- Compound constructions with "de" and "para" are common in search

**Common adaptations**:
- "freelancer" → "freelancer" or "trabajador independiente"
- "invoice" → "factura"
- "accounting" → "contabilidad"
- "tax return" → "declaración de impuestos"

## Portuguese (pt)

**Register**: Você-form, friendly, informal-professional

**Voice**:
- Use "você/seu/sua" — the natural Brazilian Portuguese informal-professional register
- Brazilian Portuguese (larger market, more natural for SaaS)
- Warm, direct, practical
- Avoid overly formal European Portuguese constructions

**Characters**:
- ALWAYS use proper Portuguese diacritics: á, é, í, ó, ú, â, ê, ô, ã, õ, ç, À, etc.
- NEVER strip accents (e.g. "começar" not "comecar", "também" not "tambem", "você" not "voce")
- Missing accents in Portuguese change meaning and look unprofessional

**SEO notes**:
- Brazilian Portuguese keywords: "software de contabilidade", "nota fiscal"
- Brazilian users search differently than Portuguese users — prioritize BR terms
- "Para" and "como" constructions common in search queries

**Common adaptations**:
- "freelancer" → "freelancer" or "profissional autônomo"
- "invoice" → "fatura" or "nota fiscal" (context-dependent)
- "accounting" → "contabilidade"
- "tax return" → "declaração de impostos"
